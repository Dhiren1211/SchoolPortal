# 🏫 SchoolPortal

**SchoolPortal** is a C# Windows Forms-based school management system that provides a digital platform for students, teachers, and administrators. 
It simplifies classroom operations such as assignment distribution, online test grading, announcements, and learning material access—all in one unified desktop application.

---

## 👥 User Roles

### 👨‍🏫 Teachers
- Create and assign **tests** and **assignments** to students
- Grade student submissions directly through the application
- Access student performance data

### 👩‍🎓 Students
- View and submit **assignments** and **tests**
- Receive **grades and feedback** from teachers
- Access **learning materials** uploaded by teachers or admins

### 👨‍💼 Admins
- Manage teacher and student user accounts
- Post school-wide **announcements**
- Maintain the overall system

---

## 🧠 Key Features
